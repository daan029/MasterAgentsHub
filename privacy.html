Privacy Policy

Last updated: 2026-08-21

MasterAgentsHub is a personal dashboard built and operated by Daan Timmermans, for his own private use only. It is not distributed to or used by any other person.

What data this connects to

This project connects to the operator's own accounts on YouTube, TikTok, and Instagram via each platform's official API, solely to read public statistics (e.g. subscriber/follower count, video or post count, total views/likes) for display on the dashboard. It does not access private messages, contacts, or any data belonging to other users of those platforms.

Where data is stored

Fetched statistics are written to a JSON file in the project's public GitHub repository, since the numbers themselves (follower counts, etc.) are already public information on the source platform. OAuth credentials needed to fetch TikTok/Instagram data are stored only as encrypted GitHub Actions secrets on the private automation side — they are never included in the public site or repository contents, and are not accessible to anyone other than the repository owner.

What this does not do

This project does not sell, share, or otherwise disclose any data to third parties. It does not use the accessed data for advertising, profiling, or any purpose beyond showing the operator his own accounts' public stats. There is no user tracking, analytics, or cookies on this site beyond what the hosting platform (GitHub Pages) applies by default.

Revoking access

Access can be revoked at any time from the connected account's own app-permissions settings on TikTok or Meta/Instagram (Login Kit / connected apps), which immediately invalidates the associated token.

Questions about this project can be directed to the repository at github.com/daan029/MasterAgentsHub.
